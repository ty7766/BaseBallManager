## 어디에 넣나

```
PhotoPipeline/input/
```

이 폴더에 **그냥 넣으면 된다.** 하위 폴더를 만들 필요 없다.

## 규칙

| | |
|---|---|
| 파일명 | **선수 이름 한글 그대로** — `김도영.jpg` · `구자욱.png` |
| 확장자 | **`.jpg` `.jpeg` `.png` `.webp` `.bmp` 아무거나** 섞여 있어도 된다. 변환 불필요 |
| 사진 종류 | **뉴스 경기 사진** (배트 든 장면 · 투구 장면 등). 정면 프로필 사진 아님 |
| 노말 · 시그 | **같은 사진** 을 쓴다 → 인물당 1장 |
| 골든글러브 | **다른 사진** 을 쓴다 → 파일명 끝에 `_골글` (`김도영_골글.jpg`) |
| CSV | **건드리지 않는다.** 파일명만 맞으면 게임이 알아서 집는다 |

다 넣은 뒤 `python PhotoPipeline/build_photos.py` 한 번이면 누끼·정렬·저장까지 끝난다.
한 장씩 넣어도 되고, 넣은 것만 카드에 붙는다.
